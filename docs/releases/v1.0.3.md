# SwiftBan 社区版 v1.0.3

v1.0.3 汇总运行管理、配置校验、白名单、定时任务和演练复核改进，并调整单接口速率规则，降低共享 NAT 客户出口下的误封风险。

## 主要变更

### 降低共享 NAT 误封风险

- `LIMIT_API_RATE` 超限现在只记录 `WATCH` 告警，不再单独触发防火墙封禁，也不会进入 dry-run 封禁候选。
- 告警包含 IP、每分钟请求数和接口。其他明确特征规则的封禁行为保持不变。

### 运维与运行控制

- 新增只读 `swiftban doctor`，汇总必需依赖、配置与白名单、目录权限、banlist、防火墙规则、运行状态及 cron/systemd 调度，并针对常见故障输出修复建议。
- `status` 展示控制状态、当前运行模式和阶段、最近一次执行结果、管理规则与调度配置。
- 新增 `stop` 停止扫描并撤销本实例管理的防火墙规则，保留 banlist 与 TTL；`start` 恢复仍有效的规则并启动正式扫描。停止状态跨重启保留，TTL 在停止期间继续计时。
- 演练结果保存为独立的 `dry-run.tsv`，增加运行 ID、UTC 起止时间、输入文件、文件筛选范围、窗口、阈值和逐文件解析计数。失败或中断不会覆盖上一次完整结果。

### 配置、白名单与定时任务

- 校验阈值、TTL、正则和白名单；无效配置、目录权限或必需防火墙链异常时，`configtest` 返回失败。
- IPv4 CIDR 校验地址和 0–32 前缀；白名单新增、删除采用规范化、语义去重和原子替换，保留注释及文件权限。
- 统一安装器与 CLI 的 cron 安装逻辑，保留自定义配置及其他任务，正确处理读取和写入失败。
- 缺少可选 `ip6tables` 时，自动检测跳过 IPv6 封禁并继续 IPv4；无法确认已有 IPv6 规则撤销时会报告失败状态。
- 过期状态清理发生读写错误时保留原 banlist。IPv6 地址按规范化形式匹配白名单、统计与手动解封。

## 升级说明

升级前备份 `/etc/swiftban/swiftban.conf` 和实际 `STATE_DIR` 中的状态文件。升级后先运行：

```bash
sudo swiftban configtest
sudo swiftban doctor
sudo swiftban run --dry-run
```

请检查演练候选和 `WATCH 单IP单接口速率` 告警，再按需启用正式检测。裸机 Nginx 通常配置 `FIREWALL_CHAIN="INPUT"`；Docker 端口映射按实际规则使用 `DOCKER-USER`。
