# SwiftBan 社区版 v1.0.5

v1.0.5 重点改进轮转日志扫描连续性、WATCH 告警复核和扫描运行诊断，并增加 Apache 日志格式支持及可重复的解析契约测试。

## 主要更新

### 轮转日志连续扫描

- 为日志文件记录 inode、文件世代和字节偏移量；活动文件重命名轮转后可继续读取原文件，并发现新的活动文件。
- 检测文件截断或末行内容重置，必要时从新世代重新读取；对轮转重叠行按日志家族去重，同时保留单文件中的重复请求。
- 游标和窗口事件快照通过原子替换一起提交。扫描失败时保留旧快照，后续运行可安全重试。

未压缩日志仍受最近3分钟文件修改时间预筛选。升级后不会回填从未登记且超过该时间范围的旧文件；gzip 压缩日志不参与扫描。`copytruncate` 可尽力识别截断和重叠，但 logrotate 复制与截断之间仍存在读取端无法消除的丢行窗口。

### WATCH 告警原始样本

WATCH 告警现在可关联同一检测窗口中的原始访问记录。每条告警最多保存5条样本，查看时不重新扫描日志目录；来源日志轮转或删除后，已保存的样本仍可用于复核，直至 WATCH 记录过期。

```bash
swiftban watch
swiftban watch --samples <告警ID>
swiftban watch --dry-run
```

### Apache 日志格式

新增 Apache common、combined 和 vhost combined 解析。`LOG_FORMAT=auto` 可与 NPM standard/proxy、Nginx combined 格式一起自动识别；也可以显式设置 `apache_common`、`apache_combined` 或 `apache_vhost_combined`。缺失 UA/Referer 的格式不会把缺失字段误当作空值参与相关检测。

### 扫描耗时与状态诊断

- `status` 在扫描时显示当前阶段已运行时间；空闲时显示最近扫描耗时及处理量。
- `doctor` 汇总最近30天成功、失败和中断扫描，展示总耗时 P50/P95、阶段耗时、最慢日志文件，并只读检查扫描快照和指标结构。
- 耗时使用 Linux 单调时钟；指标以受限权限保存30天。失败或停止时会尽可能保留已完成阶段的耗时，旧版本扫描不补生成历史指标。

```bash
swiftban status
sudo swiftban doctor
```

### 日志解析契约

增加六种自编日志格式样例，逐字段校验解析结果、格式错误计数，并精确校验聚合封禁候选和 WATCH 结果。URI、UA、Referer 中的伪造 IP 作为安全负例，确认不会被误认为客户端地址。样例测试已纳入 GitHub Actions；它是格式回归验证，不代替生产日志验收。

## 升级方式

备份 `/etc/swiftban/swiftban.conf` 和 `${STATE_DIR}`，获取 v1.0.5 后使用现有安装脚本升级：

```bash
git fetch origin --tags
git checkout v1.0.5
sudo ./install/install.sh
```

本版本不要求修改现有配置。安装后先运行 `sudo swiftban configtest`、`sudo swiftban doctor`，再使用目标服务器的脱敏日志执行 `swiftban run --dry-run` 核对解析错误和检测候选。已有封禁记录及 TTL 会保留；增量扫描游标、耗时指标和新的 WATCH 样本从升级后的扫描开始生成，不会补造旧版历史。

## 验证

发布前通过 ShellCheck、检测器、日志格式契约、维护、WATCH、IP 明细、来源地及 Linux 运行控制集成测试。GitHub Actions CI 和 Pages 部署均通过。
