## 版本规划

**定位**：生产验证的 Bash 版攻击检测与自动封禁系统

- [x] 11 个检测维度
- [x] iptables/ip6tables 双栈封禁（DOCKER-USER）
- [x] 双层白名单（内置 + 文件/CIDR）

**生产验证**：腾讯云两台服务器，累计拦截数千次攻击，零误封。

## 产品对比定位

| 方案 | 优势 | 劣势 | SwiftBan 定位 |
|------|------|------|--------------|
| 商业 WAF（阿里云/腾讯云） | 功能全、0 维护 | 贵、需 CDN 接入 | 轻量自建替代 |
| fail2ban | 成熟、插件多 | 配置复杂、误封多 | 更简单易用 |
| Nginx + Lua (OpenResty) | 高性能 | 需改 Nginx、门槛高 | 零侵入、无依赖 |
| 云原生网关 | 弹性 | 绑定云厂商 | 跨环境通用 |

**SwiftBan 差异化**：
1. **零侵入**：不改 Nginx 配置，只读日志
2. **零误封**：特征驱动 + 白名单 + 观察模式
3. **零依赖**：纯 Bash，任何 Linux 可跑
4. **Docker 友好**：DOCKER-USER 链，适配容器化部署
